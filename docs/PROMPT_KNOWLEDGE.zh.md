# 本地提示词知识库

## 目的

本地提示词知识库为提示词翻译流水线提供可复用的风格、质量和 LoRA 触发词规则，避免把所有规则硬编码在 Python 中。

## 位置

路径由 `PROMPT_KNOWLEDGE_PATH` 配置，默认是：

```text
config/prompt_knowledge.json
```

## 使用方式

本地服务会在构建提示词时加载知识库文件。修改文件后，重启服务以确保新内容生效。

## 条目建议

条目应短小并面向模型：

- 已知 LoRA 的触发词。
- 能改善本地 checkpoint 输出的风格说明。
- 常见瑕疵的负面提示词片段。
- 需要时加入 NSFW 可见性规则。

不要在此文件中放 secret、云端 token 或机器绝对路径。
