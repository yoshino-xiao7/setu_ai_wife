## 已生效的本地修改

- 默认步数 35 → 28；明确传入的步数不覆盖。调试页面提供 24 / 28 / 35 步快捷选择。
- ComfyUI 完成检测及 worker 本地结果检测间隔从 2 秒改为 0.5 秒；云端抢单间隔不变。
- 双角色 auto：无手绘区域时接入左右 area conditioning，有手绘区域时接入 A/B mask conditioning。保留 single-pass 兼容旧全局流程，inpaint 路径保留。
- 精简系统自动追加的重复人数、正向否定与身体约束；用户自己的提示词和角色描述仍保留。
- 手绘区域不再将 A/B 位置说明注入全局正向提示词，避免与实际 mask 重复及角色卡式构图干扰。mask 保留完整画面的条件计算，避免局部裁剪导致重影与重复人物。
- 日志增加 `[generation-timing]`，记录提交、排队加执行、ComfyUI 执行、下载和总耗时，不包含用户提示词或凭据。

本地 `.env` 使用 DEFAULT_STEPS=28、GENERATION_POLL_SECONDS=0.5、DUAL_CHARACTER_STRATEGY=auto。

## 性能事实及限制

设备为 RTX 3060 Laptop，6GB 显存。已确认使用 CUDA；检查时 Ollama 没有驻留模型。

初次静物测试（WAI、Euler/normal、768×1024、CFG 4.5、无 LoRA）的 ComfyUI 执行时间：首轮 28 步 28.24 秒、24 步 16.43 秒、预热后 28 步 21.67 秒。这是单场景数据，不等于人物等画质或稳定收益。

重启后固定种子 274091、1024×768 的本地 API 人物验证：35 步约 24.25 秒，默认 28 步约 25.92 秒。同期存在构建负载和温度变化，不能据此声称固定提速比例。连续双 LoRA 生成时显卡达到 86–88°C，`nvidia-smi -q -d PERFORMANCE,TEMPERATURE` 明确报告 `SW Thermal Slowdown: Active`。未调整风扇、功耗或温度保护。

旧 jobs 数据库的 updated_at 会被后续更新改写，部分记录跨度异常，不能直接当作生成耗时。后续应优先查看新的分阶段日志。

## 双人物实测

使用八重神子和雷电将军两个现有角色/LoRA，24 步、1024×768、同一随机种子、合影场景：初版区域流程约 60.43 秒，手绘区域流程约 54.44 秒。初版手绘区域图出现设定卡、文字和重复人物，因此进一步移除了全局 A/B 位置描述并精简系统约束。

精简后的左右区域复测约 42.05 秒（初版约 60.43 秒）。手绘区域使用 mask bounds 时仍出现重影，已撤回该实验设置；保留完整画面条件的实测约 32.36 秒，图中两位角色及背景完整，没有此前的重影，但服装细节和身份仍不是完全准确。以上是固定种子单场景比较，不代表稳定提速比例。区域流程仍共享两套 LoRA，不能保证身份完全隔离；左右分区也不等同于姿势控制。本次没有新增 ControlNet 模型或姿势输入接口，复杂交叉动作、手部和肢体关系仍是限制。官方原理说明：https://docs.comfy.org/tutorials/controlnet/controlnet

## 提示词生成优化

发现 qwen3:4b 使用 num_gpu=1，实际只卸载一层而非选择一块 GPU；运行时模型仅约 0.4GB 位于显存。同时仅使用 /no_think 文本，没有请求 think=false。现已修改为自动显存层分配 -1、显式 think=false，并在主请求和英文纠错请求中设置 keep_alive=0，完成后释放绘图所需显存。

新增 45 秒总超时，覆盖两路 provider 竞争、备用模型及纠错过程；取消未获胜任务后等待清理。新增 [prompt-timing] 日志，只记录结果来源及耗时。

同一简单中文场景（成年女性、银发、蓝外套、雨夜霓虹）：旧原始 Ollama 请求 42.66 秒，产生 1337 字符 thinking 而正式 response 为空；优化参数原始请求 15.92 秒，thinking 为零且英文 JSON 正常。最终重启后通过实际本地翻译 API 复测 4.17 秒，采用 Ollama 结果，返回 adult female, silver hair, blue coat, rainy street, neon lights。随后 /api/ps 模型数为 0。缓存、冷启动和机器负载不同，不能把单次结果当作固定加速比例。

API 与云端 worker 均已重启。总超时取消测试和已有测试共 41 项通过，compileall 与 Windows 环境检查通过。未改动云端翻译队列契约；如果翻译排在绘图任务后，排队时间仍可能额外增加。
